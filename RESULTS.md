### How the file identity was confirmed

At submission time there was genuine uncertainty about which of two
candidate files had actually been uploaded — `aaronteam_task2-fold3-w03.zip`
(Task 2's extra ensemble member blended in at 0.3 weight) or
`aaronteam_task2-12fold-only.zip` (the same member at full weight 1.0) — both
built and considered for submission the same day. This was resolved, not
assumed: a follow-up submission explicitly uploaded the full-weight file
(`aaronteam_task2-12fold-only.zip`) in isolation, and it scored Task2=7.33433,
Round=7.05812 — measurably worse than, and different from, the recorded best
(Task2=7.35794, Round=7.06756). Since the full-weight file's score is now
known precisely and differs from what was recorded, the original upload that
produced 7.06756 could not have been the full-weight file — by elimination,
it was `aaronteam_task2-fold3-w03.zip`, the 0.3-weight version. This
resubmission cost nothing (best-of-submission scoring keeps 7.06756 as the
recorded result regardless), and confirms which file corresponds to the
finals "same model" requirement.
